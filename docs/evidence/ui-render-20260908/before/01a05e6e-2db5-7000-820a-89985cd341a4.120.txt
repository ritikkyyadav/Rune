
   # EvoLab — Master Product, Scientific, and Engineering Implementation Prompt                                     
                                                                                                                    
   ## Mission                                                                                                       
                                                                                                                    
   You are responsible for evolving the existing **EvoLab** codebase from a gene-comparison dashboard into an       
   **interactive computational biology laboratory**.                                                                
                                                                                                                    
   Do not treat this as a request to simply add more UI components.                                                 
                                                                                                                    
   The larger objective is to create a system in which a user can:                                                  
                                                                                                                    
   **observe biological data → interrogate it → manipulate it → compute consequences → compare organisms → form     
   hypotheses → inspect evidence → understand the result.**                                                         
                                                                                                                    
   The fundamental product principle is:                                                                            
                                                                                                                    
   > **Compute first. Explain second. Preserve evidence throughout.**                                               
                                                                                                                    
   EvoLab must not become "ChatGPT for biology."                                                                    
                                                                                                                    
   General-purpose language models can already answer biological questions conversationally.                        
                                                                                                                    
   EvoLab's value must instead come from combining:                                                                 
                                                                                                                    
   1. real biological records;                                                                                      
   2. deterministic computation;                                                                                    
   3. reproducible analysis;                                                                                        
   4. interactive exploration;                                                                                      
   5. experimental manipulation;                                                                                    
   6. provenance;                                                                                                   
   7. AI-assisted reasoning over computed evidence.                                                                 
                                                                                                                    
   The AI layer must operate **on top of scientific computation**, not replace it.

   # 2. Understand the product from first principles                                                                
                                                                                                                    
   EvoLab exists because biological knowledge has several distinct layers.                                          
                                                                                                                    
   ## Layer A — Biological reality                                                                                  
                                                                                                                    
   Examples:                                                                                                        
                                                                                                                    
   - organisms;                                                                                                     
   - chromosomes;                                                                                                   
   - genes;                                                                                                         
   - transcripts;                                                                                                   
   - coding sequences;                                                                                              
   - proteins;                                                                                                      
   - amino acids;                                                                                                   
   - mutations;                                                                                                     
   - domains;                                                                                                       
   - evolutionary relationships.                                                                                    
                                                                                                                    
   ## Layer B — Scientific records                                                                                  
                                                                                                                    
   Examples:                                                                                                        
                                                                                                                    
   - NCBI Gene IDs;                                                                                                 
   - taxonomy IDs;                                                                                                  
   - RefSeq accessions;                                                                                             
   - assemblies;                                                                                                    
   - CDS records;                                                                                                   
   - transcript records;                                                                                            
   - protein accessions;                                                                                            
   - ortholog mappings.                                                                                             
                                                                                                                    
   These records are representations of biological knowledge, not biology itself.                                   
                                                                                                                    
   ## Layer C — Computational interpretation                                                                        
                                                                                                                    
   Examples:                                                                                                        
                                                                                                                    
   - sequence alignment;                                                                                            
   - pairwise identity;                                                                                             
   - coverage;                                                                                                      
   - conservation;                                                                                                  
   - codon projection;                                                                                              
   - mutation classification;                                                                                       
   - phylogenetic distance;                                                                                         
   - tree construction.                                                                                             
                                                                                                                    
   ## Layer D — Human interpretation                                                                                
                                                                                                                    
   Examples:                                                                                                        
                                                                                                                    
   - "this position is highly conserved";                                                                           
   - "human differs from chimp and gorilla here";                                                                   
   - "this nucleotide change alters the encoded amino acid";                                                        
   - "this tree is derived from TP53 sequences and is not the definitive species phylogeny."                        
                                                                                                                    
   ## Layer E — AI reasoning                                                                                        
                                                                                                                    
   AI may:                                                                                                          
                                                                                                                    
   - explain computed results;                                                                                      
   - compare findings;                                                                                              
   - summarize patterns;                                                                                            
   - help users formulate questions;                                                                                
   - translate natural-language requests into deterministic analyses;                                               
   - provide educational explanations.                                                                              
                                                                                                                    
   AI must **not invent Layer A–C results**.                                                                        
                                                                                                                    
   The architecture must preserve these boundaries.

   # 3. Product vision                                                                                              
                                                                                                                    
   The long-term product is:                                                                                        
                                                                                                                    
   # EvoLab — Interactive Computational Biology Laboratory                                                          
                                                                                                                    
   The user should feel that they are operating biological instruments rather than reading a database report.       
                                                                                                                    
   The user journey should eventually resemble:                                                                     
                                                                                                                    
   ```text                                                                                                          
   Select biological system                                                                                         
   ↓                                                                                                                
   Observe                                                                                                          
   ↓                                                                                                                
   Ask a question                                                                                                   
   ↓                                                                                                                
   Run computation                                                                                                  
   ↓                                                                                                                
   Inspect pattern                                                                                                  
   ↓                                                                                                                
   Manipulate something                                                                                             
   ↓                                                                                                                
   Recompute                                                                                                        
   ↓                                                                                                                
   Compare                                                                                                          
   ↓                                                                                                                
   Form hypothesis                                                                                                  
   ↓                                                                                                                
   Inspect evidence                                                                                                 
   ↓                                                                                                                
   Understand                                                                                                       
   ```                                                                                                              
                                                                                                                    
   This is fundamentally different from:                                                                            
                                                                                                                    
   ```text                                                                                                          
   search                                                                                                           
   ↓                                                                                                                
   read answer                                                                                                      
   ↓                                                                                                                
   leave                                                                                                            
   ```                                                                                                              
                                                                                                                    
   The second interaction has weak product value because general AI already does it well.                           
                                                                                                                    
   The first interaction can become a genuine scientific-learning environment.

   # 5. Scientific correctness is the highest priority                                                              
                                                                                                                    
   Treat biology as the hardest part of this project.                                                               
                                                                                                                    
   A visually impressive but biologically incorrect result is a failed result.                                      
                                                                                                                    
   ## Mandatory rule                                                                                                
                                                                                                                    
   The software must distinguish between:                                                                           
                                                                                                                    
   ```text                                                                                                          
   calculated fact                                                                                                  
   database annotation                                                                                              
   inference                                                                                                        
   prediction                                                                                                       
   AI explanation                                                                                                   
   ```                                                                                                              
                                                                                                                    
   Never present these as equivalent.                                                                               
                                                                                                                    
   Every important result should internally carry something equivalent to:                                          
                                                                                                                    
   ```text                                                                                                          
   value                                                                                                            
   method                                                                                                           
   source                                                                                                           
   confidence/status                                                                                                
   provenance                                                                                                       
   ```

   # 6. Ortholog and transcript selection                                                                           
                                                                                                                    
   One gene symbol can correspond to multiple transcripts and protein isoforms.                                     
                                                                                                                    
   Comparing arbitrary isoforms across species can produce meaningless or misleading results.                       
                                                                                                                    
   Therefore the resolver requires an explicit, deterministic policy.                                               
                                                                                                                    
   Prefer established database representative selections where available.                                           
                                                                                                                    
   Conceptually:                                                                                                    
                                                                                                                    
   ```text                                                                                                          
   MANE Select                                                                                                      
   ↓                                                                                                                
   RefSeq Select / equivalent representative record                                                                 
   ↓                                                                                                                
   curated complete RefSeq                                                                                          
   ↓                                                                                                                
   appropriate predicted complete RefSeq                                                                            
   ↓                                                                                                                
   deterministic fallback                                                                                           
   ```                                                                                                              
                                                                                                                    
   Do not assume that only `NM_` / `NP_` records are valid.                                                         
                                                                                                                    
   Non-human species may legitimately rely on predicted records such as:                                            
                                                                                                                    
   ```text                                                                                                          
   XM_                                                                                                              
   XP_                                                                                                              
   ```                                                                                                              
                                                                                                                    
   These must be clearly labelled in provenance.                                                                    
                                                                                                                    
   For every selected species, expose:                                                                              
                                                                                                                    
   ```text                                                                                                          
   Species                                                                                                          
   Scientific name                                                                                                  
   Taxonomy ID                                                                                                      
                                                                                                                    
   Gene ID                                                                                                          
   Gene symbol                                                                                                      
                                                                                                                    
   Transcript accession                                                                                             
   Protein accession                                                                                                
   CDS accession if applicable                                                                                      
                                                                                                                    
   Record status                                                                                                    
   Curated/predicted status                                                                                         
                                                                                                                    
   Sequence length                                                                                                  
   Selection reason                                                                                                 
                                                                                                                    
   Assembly if available                                                                                            
   Retrieval timestamp                                                                                              
   Source                                                                                                           
   ```                                                                                                              
                                                                                                                    
   Never silently choose an isoform.

   # 7. Add scientific validation gates                                                                             
                                                                                                                    
   Before allowing a sequence into the comparison, validate it.                                                     
                                                                                                                    
   Possible checks include:                                                                                         
                                                                                                                    
   ```text                                                                                                          
   Is the record protein-coding?                                                                                    
                                                                                                                    
   Is the CDS complete?                                                                                             
                                                                                                                    
   Is CDS length compatible with codon structure?                                                                   
                                                                                                                    
   Does CDS translation correspond to the selected protein?                                                         
                                                                                                                    
   Does the record belong to the expected taxon?                                                                    
                                                                                                                    
   Does the gene correspond to the intended ortholog?                                                               
                                                                                                                    
   Are ambiguous bases present?                                                                                     
                                                                                                                    
   Are there suspicious truncations?                                                                                
                                                                                                                    
   Is the protein unusually short or long relative to peers?                                                        
                                                                                                                    
   Is annotation predicted rather than curated?                                                                     
                                                                                                                    
   Is alignment coverage suspiciously low?                                                                          
   ```                                                                                                              
                                                                                                                    
   Results that fail hard invariants should not silently enter analysis.                                            
                                                                                                                    
   Results that are scientifically usable but uncertain should carry warnings.                                      
                                                                                                                    
   Example:                                                                                                         
                                                                                                                    
   ```text                                                                                                          
   Chimpanzee TP53                                                                                                  
                                                                                                                    
   Record status:                                                                                                   
   Predicted model                                                                                                  
                                                                                                                    
   Protein length:                                                                                                  
   393 aa                                                                                                           
                                                                                                                    
   Warning:                                                                                                         
   Representative transcript is computationally predicted.                                                          
   Interpret isoform-specific differences cautiously.                                                               
   ```

   # 8. Protein-first alignment                                                                                     
                                                                                                                    
   Maintain the following scientific rule:                                                                          
                                                                                                                    
   **Align proteins first.**                                                                                        
                                                                                                                    
   Do not independently align DNA and protein and assume the alignments correspond.                                 
                                                                                                                    
   Use:                                                                                                             
                                                                                                                    
   ```text                                                                                                          
   CDS                                                                                                              
   ↓                                                                                                                
   translation                                                                                                      
   ↓                                                                                                                
   protein sequence                                                                                                 
   ↓                                                                                                                
   protein multiple alignment                                                                                       
   ↓                                                                                                                
   project gaps onto original CDS codons                                                                            
   ↓                                                                                                                
   codon-aligned CDS                                                                                                
   ```                                                                                                              
                                                                                                                    
   This preserves biological correspondence between:                                                                
                                                                                                                    
   ```text                                                                                                          
   nucleotide                                                                                                       
   codon                                                                                                            
   amino acid                                                                                                       
   aligned residue                                                                                                  
   ```                                                                                                              
                                                                                                                    
   Build tests proving that this mapping remains consistent.                                                        
                                                                                                                    
   ---                                                                                                              
                                                                                                                    
   # 9. Difference representation                                                                                   
                                                                                                                    
   Do not naively represent every nucleotide difference as an independent evolutionary mutation.                    
                                                                                                                    
   A codon can differ at multiple nucleotide positions.                                                             
                                                                                                                    
   Represent:                                                                                                       
                                                                                                                    
   ```text                                                                                                          
   Reference codon                                                                                                  
   Observed codon                                                                                                   
                                                                                                                    
   Individual nucleotide differences                                                                                
                                                                                                                    
   Reference amino acid                                                                                             
   Observed amino acid                                                                                              
                                                                                                                    
   Protein consequence                                                                                              
   ```                                                                                                              
                                                                                                                    
   Example:                                                                                                         
                                                                                                                    
   ```text                                                                                                          
   Reference:                                                                                                       
   AAA → Lys                                                                                                        
                                                                                                                    
   Observed:                                                                                                        
   GGG → Gly                                                                                                        
                                                                                                                    
   Nucleotide differences:                                                                                          
   1                                                                                                                
   2                                                                                                                
   3                                                                                                                
                                                                                                                    
   Protein consequence:                                                                                             
   Lys → Gly                                                                                                        
   ```                                                                                                              
                                                                                                                    
   ---                                                                                                              
                                                                                                                    
   # 10. Gap terminology                                                                                            
                                                                                                                    
   Do not automatically label alignment gaps as biological insertions or deletions.                                 
                                                                                                                    
   Without ancestral reconstruction, directionality may be unknown.                                                 
                                                                                                                    
   Prefer language such as:                                                                                         
                                                                                                                    
   ```text                                                                                                          
   alignment gap                                                                                                    
                                                                                                                    
   codon absent relative to selected reference                                                                      
                                                                                                                    
   sequence contains additional residues relative to reference                                                      
   ```                                                                                                              
                                                                                                                    
   Only claim insertion/deletion direction when the analysis genuinely supports it.                                 
                                                                                                                    
   ---                                                                                                              
                                                                                                                    
   # 11. Tree semantics                                                                                             
                                                                                                                    
   The current tree must be treated as a **gene-sequence similarity/evolution tree**, not a definitive species      
   phylogeny.                                                                                                       
                                                                                                                    
   UI language should communicate this explicitly.                                                                  
                                                                                                                    
   Prefer:                                                                                                          
                                                                                                                    
   # Protein gene tree                                                                                              
                                                                                                                    
   or                                                                                                               
                                                                                                                    
   # TP53 sequence tree                                                                                             
                                                                                                                    
   rather than simply:                                                                                              
                                                                                                                    
   # Evolution tree                                                                                                 
                                                                                                                    
   Display:                                                                                                         
                                                                                                                    
   ```text                                                                                                          
   Derived from selected protein alignment.                                                                         
                                                                                                                    
   This represents sequence relationships for this gene and is not necessarily the definitive species phylogeny.    
   ```                                                                                                              
                                                                                                                    
   Evaluate whether Neighbor Joining is preferable to the current implementation.                                   
                                                                                                                    
   Do not casually substitute UPGMA if the product specification expects Neighbor Joining.                          
                                                                                                                    
   If multiple algorithms are eventually supported, expose them intentionally.                                      
                                                                                                                    
   Example:                                                                                                         
                                                                                                                    
   ```text                                                                                                          
   Tree method                                                                                                      
                                                                                                                    
   Neighbor Joining                                                                                                 
   Distance: amino-acid p-distance                                                                                  
                                                                                                                    
   Advanced:                                                                                                        
   ○ Neighbor Joining                                                                                               
   ○ UPGMA                                                                                                          
   ○ external inferred tree                                                                                         
   ```                                                                                                              
                                                                                                                    
   Do not imply bootstrap support unless it was actually calculated.

   # 15. Instrument 3 — Comparative Query Engine                                                                    
                                                                                                                    
   The user should be able to ask deterministic questions about an existing alignment.                              
                                                                                                                    
   Examples:                                                                                                        
                                                                                                                    
   > Show positions where human differs from chimpanzee.                                                            
                                                                                                                    
   > Show positions where human differs but chimpanzee and gorilla match.                                           
                                                                                                                    
   > Find residues conserved across every selected species.                                                         
                                                                                                                    
   > Find positions conserved in mammals but different in zebrafish.                                                
                                                                                                                    
   > Show variable codons that do not change the amino acid.                                                        
                                                                                                                    
   > Show amino-acid changes unique to the selected reference species.                                              
                                                                                                                    
   These are not fundamentally LLM questions.                                                                       
                                                                                                                    
   They are structured queries over biological data.                                                                
                                                                                                                    
   Implement an internal query representation.                                                                      
                                                                                                                    
   For example, conceptually:                                                                                       
                                                                                                                    
   ```text                                                                                                          
   FILTER positions                                                                                                 
   WHERE                                                                                                            
   human != chimpanzee                                                                                              
   AND                                                                                                              
   chimpanzee == gorilla                                                                                            
   ```                                                                                                              
                                                                                                                    
   Do not hard-code only these examples.                                                                            
                                                                                                                    
   Design the underlying primitives so more comparative questions can be expressed later.                           
                                                                                                                    
   Possible primitive concepts:                                                                                     
                                                                                                                    
   ```text                                                                                                          
   equals                                                                                                           
   not_equals                                                                                                       
   matches_reference                                                                                                
   differs_from_reference                                                                                           
   conserved_across                                                                                                 
   variable_across                                                                                                  
   present_in                                                                                                       
   absent_relative_to                                                                                               
   gap_state                                                                                                        
   synonymous                                                                                                       
   nonsynonymous                                                                                                    
   species_group                                                                                                    
   selected_clade                                                                                                   
   position_range                                                                                                   
   conservation_threshold                                                                                           
   ```                                                                                                              
                                                                                                                    
   Architect the system as a composable analysis engine.

   # 16. Instrument 4 — AI command interface                                                                        
                                                                                                                    
   Only after deterministic query operations exist should a natural-language interface be added.                    
                                                                                                                    
   Architecture:                                                                                                    
                                                                                                                    
   ```text                                                                                                          
   User language                                                                                                    
   ↓                                                                                                                
   LLM                                                                                                              
   ↓                                                                                                                
   structured EvoLab operation                                                                                      
   ↓                                                                                                                
   validation                                                                                                       
   ↓                                                                                                                
   deterministic analysis engine                                                                                    
   ↓                                                                                                                
   structured result                                                                                                
   ↓                                                                                                                
   LLM explanation if useful                                                                                        
   ```                                                                                                              
                                                                                                                    
   Not:                                                                                                             
                                                                                                                    
   ```text                                                                                                          
   User language                                                                                                    
   ↓                                                                                                                
   LLM guesses biological answer                                                                                    
   ```                                                                                                              
                                                                                                                    
   Example:                                                                                                         
                                                                                                                    
   User:                                                                                                            
                                                                                                                    
   > Show me where humans differ but chimpanzee and gorilla are the same.                                           
                                                                                                                    
   Model should produce a structured operation equivalent to:                                                       
                                                                                                                    
   ```text                                                                                                          
   reference = human                                                                                                
                                                                                                                    
   condition:                                                                                                       
   human != chimpanzee                                                                                              
   human != gorilla                                                                                                 
   chimpanzee == gorilla                                                                                            
   ```                                                                                                              
                                                                                                                    
   The EvoLab engine performs the calculation.                                                                      
                                                                                                                    
   Then the AI explains the actual returned result.                                                                 
                                                                                                                    
   ---                                                                                                              
                                                                                                                    
   # 17. Never let AI become the scientific oracle                                                                  
                                                                                                                    
   AI is allowed to:                                                                                                
                                                                                                                    
   - formulate queries;                                                                                             
   - summarize;                                                                                                     
   - teach;                                                                                                         
   - compare;                                                                                                       
   - contextualize;                                                                                                 
   - explain terminology;                                                                                           
   - generate human-readable narratives.                                                                            
                                                                                                                    
   AI is not allowed to fabricate:                                                                                  
                                                                                                                    
   - sequence identities;                                                                                           
   - residue positions;                                                                                             
   - codons;                                                                                                        
   - protein accessions;                                                                                            
   - alignments;                                                                                                    
   - mutation classes;                                                                                              
   - conservation scores;                                                                                           
   - tree topology;                                                                                                 
   - transcript selections;                                                                                         
   - source provenance.                                                                                             
                                                                                                                    
   These must come from deterministic tools or source databases.


   # 25. Infrastructure philosophy                                                                                  
                                                                                                                    
   Do not overengineer.                                                                                             
                                                                                                                    
   The current workload is generally computationally light.                                                         
                                                                                                                    
   Typical analysis:                                                                                                
                                                                                                                    
   ```text                                                                                                          
   2–6 sequences                                                                                                    
   hundreds or thousands of residues                                                                                
   ```                                                                                                              
                                                                                                                    
   No GPU is required.                                                                                              
                                                                                                                    
   The important bottlenecks are:                                                                                   
                                                                                                                    
   ```text                                                                                                          
   external data retrieval                                                                                          
   record quality                                                                                                   
   scientific validation                                                                                            
   correctness                                                                                                      
   UX                                                                                                               
   ```                                                                                                              
                                                                                                                    
   not raw compute.                                                                                                 
                                                                                                                    
   Possible initial architecture:                                                                                   
                                                                                                                    
   ```text                                                                                                          
   Next.js                                                                                                          
   ↓                                                                                                                
   FastAPI                                                                                                          
   ↓                                                                                                                
   scientific analysis modules                                                                                      
   ├─ NCBI                                                                                                          
   ├─ MAFFT                                                                                                         
   └─ Biopython/custom algorithms                                                                                   
                                                                                                                    
   PostgreSQL                                                                                                       
   ```                                                                                                              
                                                                                                                    
   Add:                                                                                                             
                                                                                                                    
   ```text                                                                                                          
   Redis                                                                                                            
   worker queues                                                                                                    
   object storage                                                                                                   
   ```                                                                                                              
                                                                                                                    
   only where actual workloads justify them.                                                                        
                                                                                                                    
   Do not introduce:                                                                                                
                                                                                                                    
   ```text                                                                                                          
   Kubernetes                                                                                                       
   distributed computing                                                                                            
   GPU infrastructure                                                                                               
   Spark                                                                                                            
   Ray                                                                                                              
   large-scale microservices                                                                                        
   ```                                                                                                              
                                                                                                                    
   without demonstrated requirements.                                                                               
                                                                                                                    
   ---                                                                                                              
                                                                                                                    
   # 26. Caching                                                                                                    
                                                                                                                    
   Caching is strategically important.                                                                              
                                                                                                                    
   Biological analyses are often repeated.                                                                          
                                                                                                                    
   Create a deterministic analysis fingerprint based on appropriate inputs such as:                                 
                                                                                                                    
   ```text                                                                                                          
   gene identity                                                                                                    
   species IDs                                                                                                      
   selected accession versions                                                                                      
   algorithm versions                                                                                               
   parameters                                                                                                       
   schema version                                                                                                   
   ```                                                                                                              
                                                                                                                    
   Reuse identical valid analyses.                                                                                  
                                                                                                                    
   Never return stale biological data silently.                                                                     
                                                                                                                    
   Define a source/version policy.                                                                                  
                                                                                                                    
   An analysis should always remain reproducible against the exact accessions originally used even if newer         
   annotations later become available.                                                                              
                                                                                                                    
   ---                                                                                                              
                                                                                                                    
   # 27. Reproducibility                                                                                            
                                                                                                                    
   Every completed analysis should be reconstructible.                                                              
                                                                                                                    
   Store enough information to determine:                                                                           
                                                                                                                    
   ```text                                                                                                          
   what records were used                                                                                           
   what versions                                                                                                    
   what algorithms                                                                                                  
   what parameters                                                                                                  
   what software versions                                                                                           
   what resulting alignment                                                                                         
   what calculations                                                                                                
   ```                                                                                                              
                                                                                                                    
   A future researcher should be able to answer:                                                                    
                                                                                                                    
   > Why did EvoLab show this value?                                                                                
                                                                                                                    
   without reverse engineering application state.

   # 28. Testing philosophy                                                                                         
                                                                                                                    
   Tests should establish biological invariants, not merely implementation behavior.                                
                                                                                                                    
   Avoid the failure mode:                                                                                          
                                                                                                                    
   ```text                                                                                                          
   wrong implementation                                                                                             
   +                                                                                                                
   tests written around wrong implementation                                                                        
   =                                                                                                                
   green CI                                                                                                         
   ```                                                                                                              
                                                                                                                    
   Use independent reference cases where possible.

   # 40. Architectural decision discipline                                                                          
                                                                                                                    
   Do not follow this document mechanically when evidence indicates a better solution.                              
                                                                                                                    
   This document provides:                                                                                          
                                                                                                                    
   ```text                                                                                                          
   vision                                                                                                           
   principles                                                                                                       
   constraints                                                                                                      
   scientific invariants                                                                                            
   product direction                                                                                                
   ```                                                                                                              
                                                                                                                    
   It does not prescribe every implementation detail.                                                               
                                                                                                                    
   For meaningful architectural decisions:                                                                          
                                                                                                                    
   1. identify the actual problem;                                                                                  
   2. identify constraints;                                                                                         
   3. inspect current implementation;                                                                               
   4. generate reasonable alternatives;                                                                             
   5. evaluate trade-offs;                                                                                          
   6. select the simplest adequate approach;                                                                        
   7. document the decision;                                                                                        
   8. implement;                                                                                                    
   9. test;                                                                                                         
   10. verify against the original goal.                                                                            
                                                                                                                    
   Prefer reversible decisions early.                                                                               
                                                                                                                    
   Do not introduce complexity because it appears "production-grade."

   ```text                                                                                                          
   FOXP2                                                                                                            
   ```

   The UI highlights those positions.                                                                               
                                                                                                                    
   The user selects one.

   ```text                                                                                                          
   Gorilla amino acid                                                                                               
   Mouse amino acid

   Mouse codon                                                                                                      
                                                                                                                    
   Conservation                                                                                                     
                                                                                                                    
   Exact source accessions                                                                                          
   ```                                                                                                              
                                                                                                                    
   The user changes one nucleotide.

   ```text                                                                                                          
   codon                                                                                                            
   amino acid                                                                                                       
   molecular consequence                                                                                            
   ```

   > Why is this interesting?

   ```text                                                                                                          
   observation                                                                                                      
   calculation                                                                                                      
   interpretation
   ```                                                                                                              

   ```text                                                                                                          
   Show evidence
   ```                                                                                                              
