# User skills, run — 2026-09-08

Evidence for P12.3: a skill added from a path, listed with its description and
origin, and invoked in a session.

**What is real here and what is not.** The `rune skill` transcript is a verbatim
capture of the real CLI. The session transcript drives the real engine and the
real slash-command code — `engine.listSkills()` for `/skills`,
`userSkillCommands(...).render()` for `/<name>` — but the model behind it is the
repository's scripted `MockProvider` (`tests/eval/mock-provider.ts`). This lane
had no API credits and no local free route, so the model's reply below was
written by the script, not generated. Everything on Rune's side of the boundary
is real, including the assertion at the end that the SKILL.md body reached the
provider inside the request.

Both runs used a throwaway workspace and a throwaway `RUNE_HOME`. Nothing read
or wrote the real `~/.rune`.

rune home.
