# Rune v1.4.11

The redesigned Rune presentation is published to the default GitHub branch and included in
the released CLI. This release includes all v1.4.10 reliability and environment-isolation fixes.

## Presentation

- A concise README with real terminal captures on a white background using Rune's Light / Matte
  theme, without the gear logo or badge wall.
- A responsive sign-in completion page using only the Rune name, with the message
  “Logged in successfully.”
- An original Canvas particle field with pointer repulsion, parallax, and ripples. Motion can be
  paused and respects reduced-motion preferences. Animation stops while the tab is hidden.
- All page assets are included in the CLI. No external fonts, scripts, or network requests are
  needed to display the page.

## Correct completion

The browser receives the success page only after OAuth state validation, token exchange, and
credential persistence complete. Failure returns a generic error, and the callback query is
removed from the browser's address bar after success. The same completion behavior applies to
provider and MCP sign-in.

## Update

```sh
rune upgrade
rune --version
```

Restart an existing Rune session after upgrading. The new page appears at the end of the next
successful browser sign-in; a previously opened callback tab belongs to its original login attempt.

## Validation

Regression tests cover delayed exchange and persistence, invalid state, failed exchange, failed
storage, duplicate callbacks, escaped provider names, the script's Content Security Policy hash,
pointer interaction, pause/resume, and reduced motion. The installed CLI can be exercised against
a local OAuth server with `scripts/verify-login-installed.ts`, without a hosted provider call.

GitHub Actions builds and checks the release artifacts, verifies checksums and version reporting,
and runs clean installation checks on macOS, Linux, and Windows. Exact results are available in
the linked release's workflow run.
