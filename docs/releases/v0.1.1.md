# Rune v0.1.1

The provider rosters are current again. The first public version shipped model lists that
had rotted behind the vendors: ChatGPT (Codex) did not offer GPT-6 Astra, the OpenAI preset
still led with GPT-5 and GPT-4o, Google led with Gemini 2.5, xAI with Grok 4, DeepSeek with
ids the vendor no longer lists. This version brings every first-party roster to the ids each
vendor documents today and fixes the code paths that decide how a model is spoken to.

## Install or upgrade

```sh
curl -fsSL https://raw.githubusercontent.com/ritikkyyadav/Rune/main/scripts/web-install.sh | bash
```

An existing install can run `rune upgrade`.

## What changed

- **ChatGPT (Codex).** GPT-6 Astra is the default, with GPT-5.6 Sol, Terra and Luna beside
  it. GPT-5.5 is not listed: OpenAI retires it from Codex on 14 October 2026.
- **OpenAI API.** GPT-6 Astra and Astra Pro, the GPT-5.6 line, GPT-5.5, GPT-5.4 mini and
  nano. GPT-5, GPT-4o and o3 are gone from the seed list.
- **Anthropic.** Claude Opus 5 stays the default (the vendor's own recommendation for most
  work); Claude Fable 5.1 is listed for demanding reasoning and long-horizon agentic work,
  with Sonnet 5 and Haiku 4.5, and Opus 4.8 and Sonnet 4.6 as legacy.
- **Google.** Gemini 3.8 Flash is the default; 3.5 Flash, 3.5 Flash-Lite, 3.1 Pro (preview),
  and the 2.5 line remain available.
- **xAI.** Grok 4.6 is the default, with 4.5, 4.3, Build 0.1 and 4.20.
- **DeepSeek.** The two ids the vendor lists today: `deepseek-flash` (V4.1 Flash) and
  `deepseek-v4-pro`.
- **Groq, Mistral, Moonshot, Cerebras, Vertex, Bedrock, Azure OpenAI.** Refreshed to each
  vendor's current documentation; deprecated ids removed.
- **GitHub Models** was retired by GitHub on 30 July 2026 and is removed; a saved
  configuration that still names it falls back to auto-detection with a notice.
- **Header.** The pinned header reads the product version (`v0.1.1`) rather than a build
  marker, and shows the last eight characters of the current session's id beside it. That
  tail is what `/sessions` and `rune list` show, and `rune resume <tail>` accepts it.
- **Transports.** The Codex and OpenAI transports recognised reasoning models by a `gpt-5`
  prefix, so a GPT-6 model would have been sent without reasoning and with the wrong
  token parameter. Both now recognise the GPT-6 family. Context and output limits for the
  new families are in the tokenizer tables.

## Platforms

Windows binaries (`rune-windows-x64.exe`, `rune-tools-windows-x64.exe`) and `install.ps1` ship
with this version as a **preview**: the release workflow installs the pair on a fresh Windows
runner and runs `--version`, `doctor`, `tools-smoke` and a headless prompt, but there is no OS
sandbox on Windows (3rd and 4th gear run shell commands uncontained; `/status` reads
`NOT ISOLATED`), the build is x64 only, and the author does not use Rune on Windows day to day.
WSL2 with the Linux install is the supported route to the sandbox. macOS and Linux are supported
as stated in v0.1.0.

## Unverified, and stated

- The accepted reasoning-effort values for GPT-6 Astra on Codex have not been measured
  live; the requested effort is passed through unchanged.
- Amazon Bedrock lists the documented InvokeModel ids; Opus 5, Sonnet 5 and Fable 5.1 on
  Bedrock use a newer endpoint shape this build does not route yet.
- The seed lists for the smaller OpenAI-compatible hosts were not refreshed; `rune models
<provider>` discovers each host's live catalogue, which is the list the picker uses.
- Ollama Cloud's lineup is unchanged; its free-plan set was last verified live on
  2026-08-26.
- Google's model page and changelog name Gemini 3.8 Flash and 3.5 Flash, but one API key
  checked during this release saw a live catalogue without them. The picker always shows
  what your own key can see (`rune models google`), so a project that has not been given
  the newer models lists the ones it has.
- Prices for the new ids are estimates carried over from the models they replace, marked as
  such in the pricing table; the cost meter is indicative for them until rates are read from
  each vendor's card.

Everything else is as in v0.1.0. See that version's notes for what is verified,
experimental, platform-limited and unresolved.
