# Rune v1.3.1

A patch on v1.3.0. On macOS, the keychain dialog that appeared every time Rune started is gone.
And the model lists catch up with what the vendors have shipped, including models released
after this version.

## Install or upgrade

```sh
curl -fsSL https://savoir.services/install.sh | bash
```

An existing install can run `rune upgrade`.

## What changed

- **No more login-password prompt on every launch.** macOS kept asking: "security wants to use
  your confidential information stored in "rune"". The item was the key Rune signs its memory
  with. It had been stored with an access list that locked out every program, Rune included,
  so every read asked for your password. That is true of every release from v0.1.0 to v1.3.0.
  A failed read also made it worse: it was never remembered, so the next check asked again, and
  a refused read could replace the real key with a new one. The key now moves to a new keychain
  item, "Rune memory key", with the default access list. The move needs the old item read one
  last time, so the first launch after upgrading shows a one-line notice, then the dialog once.
  After that, never again.
- **The latest models.** GPT-6 Sol and GPT-6 Luna, released 2026-09-22, join GPT-6 Astra on
  Codex and become its standard and light tiers. Claude Opus 5.5 is the new Anthropic default.
  xAI's grok-4.7 is added. OpenRouter gains Qwen3.8 27B as a free model, and GLM-5.2's free
  listing is removed. The prices are the vendors' published rates as of 2026-09-28.
- **`/model` shows what your account can use, not only what this version knew.** For a signed-in
  account, Rune now reads the provider's own model list and merges it into the built-in one.
  That covers the Codex catalogue and the OpenAI API's list. A model released after v1.3.1 still
  appears. Built-in entries are never dropped, dated snapshot ids fold into their names, and
  non-text models (speech, images, live audio) are left out. `rune models codex --refresh` shows
  what your account's list contains.
- **The cost column had astra at an eighth of its price.** GPT-6 Astra carried an estimated
  $1.25 in and $10 out per million tokens; its published rate is $10 and $50. Sessions on astra
  now show their real metered-equivalent cost. On a Codex plan the marginal cost is still zero;
  the column answers "what would this have cost on the API".

## Unverified, and stated

- The keychain fix's tests never touch a real keychain, by design. Its live check is the first
  launch after upgrading: one notice, one dialog, then none. A dialog that still appears later
  and names "rune" rather than "Rune memory key" is a provider's stored key, which is a
  different item.
- Live model discovery has not yet been run against real Codex and OpenAI accounts.
- Codex filters its catalogue by client version. Rune asks as the newest published Codex CLI,
  looked up once per launch with a 1.5-second limit, and falls back to a built-in version when
  the lookup fails.

Everything else is as in v1.3.0.
