# Rune v1.4.17

A patch on v1.4.16. The interface stops destroying work and stops saying `done` when it is not.
Everything here comes from an audit of 1.4.15 in a real pseudo-terminal: 285 frames of the
shipped CLI against a scripted local model, at 80×24 up to 160×48, dark and light.

## Install or upgrade

```sh
curl -fsSL https://savoir.services/install.sh | bash
```

An existing install can run `rune upgrade`.

## What changed

**Keys that no longer destroy work.**

- **Option and Alt keys** were read as Escape: Option+left cleared the draft, and mid-run it
  stopped the run. They now move and delete by word; Option+Enter is a newline; any other Option
  chord does nothing. `ctrl+w` deletes the previous word.
- **Stopping a run takes two presses of Esc.** The first says `esc again to stop`. Esc out of a
  sub-agent's transcript steps back to the agents instead of stopping everything.
- **The approval card no longer answers to letters.** A sentence typed as it opened could approve
  shell commands for the session on its first `a`. Digits and Enter answer once the card has been
  up half a second and typing has paused; what you typed is kept for after.
- **Ctrl+L redraws** instead of erasing the transcript. `/clear` still clears.

**A screen that says what happened.**

- **The row under the transcript says how a turn ended:** done, checks failing, stopped by you,
  stopped on an error, rate-limited, paused at the usage limit, ran out of turns. It said `done`
  after every one of them.
- **No more invented progress.** When nothing arrives the row says `waiting on the model`; a
  provider error being retried is named; the retry count runs across the whole turn.
- **Answers are their own blocks.** A reply after a failed check was glued to the last one
  mid-sentence; an answer's first line printed raw backticks.
- **Stopped sub-agents wear `~`, never a tick,** and a "No" on the approval card is your choice,
  not a red failure.
- **Each sub-agent's row is named by the agent and moves while it works:** what it was sent to
  do, what it is doing now, for how long. One that came back with nothing says so in words.
- **Errors keep their start and their end,** with workspace-relative paths.
- **Edit previews lead with the change**, and `ctrl+o` scrolls to what it opened.

**Settings a new person can read.**

- **A first launch asks which model:** a subscription you have, an API key, or a model on your
  machine. Esc says nothing runs until one is connected, a message sent before then is kept, and
  the status line says `no model -- /login` instead of naming a default with no key. `/setup`
  still opens the full wizard.
- **`/config` is a short Settings page** with values in words (`no limit`, `3rd gear -- edits +
sandboxed shell`); the harness's own dials are under Advanced.

**Smaller things.** Code blocks copy cleanly (no side borders), and `/copy` copies the last
answer's code. Added lines meet 4.5:1 contrast against their band. One separator in receipts; a
stop, a steer and a re-plan are one row each; answered questions keep their question; hints are
cut at a word; `1 line`; `/status` no longer repeats the header; the session picker says how long
ago; the frame draws down to 60×12.

## Checked, and stated

- **In real pseudo-terminals, against a scripted model on loopback:** ten scenarios replayed with
  the exact bytes terminals send (Option keys, Esc presses, a sentence typed onto an approval card,
  a declined command, provider errors 500 and 429, a failing check, a fan-out of two sub-agents
  stopped mid-run, a first launch with nothing connected, `/config`, a 60×12 window). 45 of 45
  checks passed. No paid model was called and credentials were scrubbed; the first-launch
  scenario only looks and presses Esc, so the key step and the login keychain are never reached.
  The rig ships in `scripts/tui-capture/trust/`.
- **46 deliberate breakages, all caught:** 17 for the first batch and 29 for the second. One
  survived at first (a rate limit followed by a different error) and now has a test.
- **Contrast measured from the colours Rune emits** (WCAG formula): the lowest added-line ratios
  were 2.79:1 and 2.69:1 before; every syntax colour on a band is now at least 4.5:1.
- **Suites:** unit 8,275 passed and 0 failed; integration 492 and 0 (run against the 1.4.16
  `rune-tools`, since this release changes no Rust code); typecheck 15 of 15 and lint 7 of 7.

## Known, and stated

- **The white added band on dark terminals** is unchanged; it is the founder's art direction.
- **`›` still means several things,** the plan's pending mark is still the letter `o`, and the
  header still spans the window while block rules are inset by a cell. Each is a frozen mark or a
  documented design, and changing it is the founder's call.
- **A rate limit does not yet say when it will retry,** there is no in-app find, and the left
  arrow on an empty composer still opens the session manager.
- **Live look owed.** Every check here ran against a scripted model in a pseudo-terminal; a session
  with a real model and a person at the keyboard has not been run on this build.
