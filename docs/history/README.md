# History

Design documents from before the product settled on its name and shape, kept as the record of how
the parts got built. The product has carried three earlier names — **Berne** (July 2026), **Alan**
(August 2026) and **Gear** (from 2026-08-25) — before becoming **Rune** on 2026-09-03. That rename
updated the product name inside these files and in their filenames; dates, decisions and paths
otherwise read as they were written, so a document here may describe a `~/.alan` data directory or a
`berne login` command that the current build only reads through migration shims.
